# Contributing

Thank you for contributing to this project.

This is a beginner-friendly project built with HTML, CSS, and JavaScript. Contributions of all skill levels are welcome.

## Getting Started

### 1. Fork the repository

Create a fork of the repository on GitHub.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/Clon-Web-FC-Barcelona.git
cd Clon-Web-FC-Barcelona
```

### 3. Create a branch

Do not work directly on `main`.

```bash
git checkout -b your-branch-name
```

Use a descriptive name, for example:

```bash
git checkout -b fix-mobile-menu
```

## Choose an Issue

Look for issues labeled:

* `good first issue`
* `beginner`
* `help wanted`

If an issue is not assigned, comment that you would like to work on it.

## Make Your Changes

Keep your changes focused on the issue.

Before opening a Pull Request:

* Test your changes.
* Check desktop and mobile layouts when applicable.
* Make sure you did not break existing functionality.

## Commit

Use a clear commit message:

```bash
git add .
git commit -m "fix: correct mobile navigation"
```

Examples:

```text
fix: correct mobile navigation
style: improve responsive layout
feat: add player section
docs: update documentation
```

## Push and Open a Pull Request

Push your branch:

```bash
git push origin your-branch-name
```

Then open a Pull Request on GitHub.

In your Pull Request:

* Explain what you changed.
* Reference the related issue.
* Include screenshots for visual changes when applicable.

Example:

```text
Closes #12
```

## Keep It Simple

Keep Pull Requests small and focused. Avoid mixing unrelated changes.

If you are new to Git, GitHub, HTML, CSS, or JavaScript, feel free to ask questions in the issue.

Thank you for contributing.
